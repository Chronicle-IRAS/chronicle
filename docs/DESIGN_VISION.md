# Design Vision — One Page

Current direction: user-authorized complete restart, October 2026. This supersedes the former fixed eight-scene journey, scene locks and prescribed transition sequence.

CHRONICLE is a naturally scrolling personal space for projects, experiments and interests. Red and black define its identity; editorial typography and deliberate spacing carry the content. The reference site informed the strong dark visual presence, but terminal styling was explicitly rejected by the user.

## Experience

1. Introduce the creator against a red/black faceted human silhouette with flowing hair, a muted moon and thin orbital rings. Follow the supplied October 27 concept composition: left-aligned serif title, artwork on the right. The current implementation uses original generated artwork and GPU-driven texture fragments. Hover creates refraction trails; holding disperses the figure and releasing restores it. Native scroll carries the portrait into a fragment-field transition. Touch/keyboard have equivalent buttons and reduced motion retains static artwork.
2. Present real projects with distinct abstract cover artwork and category filters.
3. Invite participation through a technology-composition experiment.
4. Explain interests through expandable, readable descriptions.
5. Finish with a red contact section linking to the real GitHub profile and source.

Interactions should reveal information or offer meaningful play. Keep native scrolling, keyboard access, touch usability and reduced-motion behavior. Never gate reading behind animation. No invented personal credentials or unconfigured destinations.

The composition engine remains pure and unordered, with derived results. The active ball lab uses local low-frequency selection/result state, while legacy graph state is retained only for compatibility. The legacy journey source remains available but is not part of the current mounted site. Future work should target the one-page entry unless explicitly restoring the old experience.

The playground is now an orbital fusion experiment: visible balls, drag-to-attract, release-to-combine, explicit project/concept outcomes and split-to-retry. Every content section offers participation: portrait deformation, interactive project studies, fusion discovery, interest selection and an elastic closing connection. React Flow removal is explicitly user-authorized.
